## 保留已审核目标框及标签

- 新增“保留显示已审核目标框及标签”开关，位于 03 的显示选项中，默认勾选。审核完一个目标并切换到下一个时，本图已审核目标的框和标签继续显示，可随时取消勾选。
- 可独立于“叠加显示全部目标”和“显示非当前标注目标的标签”生效。只开启保留选项时，显示当前算法目标和本图已完成审核的算法目标，其余未审核目标隐藏。
- 正检立即计入已审核；误检需确认原因或按 Enter 跳过原因。仅填写备注、误检原因待确认的目标仍按未完成处理。
- 清除或撤销审核后同步更新显示；切换图片、按置信度排序及重新打开已保存进度时，保留显示与对应目标一致。
- 标签内容遵循 02 中算法框样式的文字选项。GT 与人工补框继续使用各自的显示规则。
- 更新 README 和详细使用指南，补充开关及其与其他显示选项的配合方式。
