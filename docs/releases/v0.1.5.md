## 功能新增

- **支持归一化坐标**：字段映射新增“归一化坐标”选项，数组字段和四个独立字段的 `xyxy` / 左上角形式 `xywh` 均可使用。算法与 GT 独立配置，默认仍按像素坐标解释。
- 归一化坐标按匹配图片的实际宽高换算；尺寸在后台按需读取，每张图片在一次导入中只读取一次。表格、叠加框、IoU 匹配、审核和报告统一使用换算后的像素坐标，输入 JSON 保留原值。
- **“叠加匹配 GT”默认勾选**，继续记住用户手动开启或关闭的设置；GT 始终只作人工参考。

## 性能优化

- 修复图片较多时，01 选择图片目录及 02 导入 JSON 后长时间卡顿的问题。批量填充期间暂停自动列宽计算，完成后统一调整，保留按内容显示列宽的能力。
- 避免刷新数据时重复加载当前图片；普通审核只更新当前图片的进度行。算法、GT 和人工补框列表也采用批量刷新。
- 本机使用 **3708 张小图、11819 条模拟检测记录**验证：01 总耗时由约 **66 秒降至 0.52 秒**，02 由约 **133 秒降至 0.78 秒**。实际耗时取决于图片、JSON 结构和磁盘等条件。

## 问题修复

- 修复字段映射选择“四个独立字段”时，`xmax` / `ymax` 与目标种类、置信度控件重叠的问题。坐标区随当前模式调整高度，小窗口支持滚动，确认和取消按钮固定在底部。
- GT 的叠加标签、悬停提示和样式预览不再显示置信度，GT 框样式中移除置信度选项；即使 JSON 带有分数或旧设置曾开启显示，也不会在 GT 标签上出现。算法标签继续按自身配置显示置信度。
- 无法读取图片尺寸时，归一化导入会记录问题，其他可处理的图片继续导入。
