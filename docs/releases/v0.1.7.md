本版本汇总 **v0.1.6 正式版之后的全部更新**，包含预发布期间的修改及后续完善。

## 功能新增

- 新增右侧底部固定的 **05 保存与导出**，保存进度、导出 Excel 和导出有效目标 JSON 各自独立，复核过程中也可以使用。
- 新增 **导出有效目标json**：仅导出算法正检和人工补充的漏检，一条目标一个元素，统一为无嵌套的 JSON 数组。固定字段为 `name, width, height, type, type_name, conf, x, y, w, h`；坐标统一为归一化的左上角 `xywh`。
- `type` 保留复核时算法 JSON 的原始数值或字符串类型；`type_name` 使用 type-mapping 的显示名称并统一为字符串。置信度缺失时输出 JSON `null`，人工补漏置信度固定为 `1.00000000`；置信度和坐标保留八位小数，不使用科学计数法。
- Excel 复核报告新增 **正检、误检、漏检** 三个独立工作表，各自提供总数、种类统计和可筛选的目标列表，并可直接跳到列表。原有复核概览、图片进度、目标明细继续保留；未完成图片上已有的标记也会计入。
- 导出有效目标时，问题与处理结果可保存为 **`文件名_导出检查.xlsx`**，支持按严重程度、问题、图片和目标筛选，便于后续处理。
- 新增人工补漏种类的明确类型选择，区分数值 `0` 和字符串 `"0"`；双击人工补框表格的种类列可修改种类，支持撤销。

## 问题修复与完善

- 导出前检查缺失尺寸、种类、无效坐标等阻断问题，可选择图片目录读取尺寸、批量补充宽高，或返回 02 检查字段映射；只有明确选择“仅导出有效目标”时才会跳过有错误的目标。
- 缺少置信度、未命中 type-mapping、旧版手写补漏种类和越界框作为提示记录，不擅自更改种类或裁剪目标框。JSON 与检查报告成对写入，失败时保护已有导出文件，并防止覆盖输入文件。
- 02 字段映射增加可选的图片宽高字段并检查冲突，区分图片尺寸和目标框宽高。补充此前漏映射的种类、置信度时，在同一原始文档和相同图片、坐标映射下保留原有审核结论。
- 保存图片尺寸来源及 type-mapping 内容，便于交接和后续导出；新增的辅助尺寸映射不改变旧目标标识，兼容旧版标注记录。
- 保留旧版本手工输入种类的字符串类型；不会仅因内容是数字或与显示名称相同就自动转换。GT 始终只作参考，不作为有效目标导出的数据来源。

## 文档与测试素材

- 更新 README、详细使用指南、界面示意图、打包说明和固定格式 JSON 示例。
- 测试素材生成脚本补齐归一化 xywh 的分组、平铺、数组、四个独立字段四种示例，可复现 `08`～`11` 测试 JSON。
- 219 项自动测试通过；single、folder 两种 Windows 64 位程序各执行 59 项打包后运行检查。COCO128 的 9 种 JSON 结构、每种 929 个目标已验证固定格式导出及重新导入。

## 下载与升级

- **单文件版**：直接运行 `DetRetLabel-single.exe`；也可下载对应 ZIP。
- **文件夹版**：完整解压 `DetRetLabel-folder-win64.zip`，运行其中的 `DetRetLabel.exe`，保留 `_internal` 文件夹。
- 两种版本均为 Windows 64 位，无需安装 Python、Qt 或 Excel。正式版作者为 **H9elix**，打包标识为 **Build20261029**。
- 升级或换机请保留完整图片目录（含 `.detretlabel/annotations.json`）、原始算法 JSON 和相同字段映射。旧记录缺少尺寸时可在导出检查中补充，无需重新标注。
- `SHA256SUMS.txt` 和 `build-manifest.json` 提供附件校验值、依赖版本、运行检查及构建来源。
