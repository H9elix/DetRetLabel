# 漏检复核流程（已实现）

以下为流程摘要，完整操作说明以[详细使用指南](使用指南.md)为准。

1. 03 只审核算法目标的正检 / 误检，没有补框按钮，按 B 也不补框。本图全部审核完或点击全部正检后，自动进入复核；最后一个误检的原因确认 / 跳过后自动切换。也可在 03 未完成时手动进入 04，原有结论、备注和原因草稿保留。
2. 自动进入或按 R 进入 04 后，临时显示全部算法结果；GT 的显示完全取决于显示 GT 按钮，不自动开启。GT 仅供人工观察，不能直接变成最终标注，也不影响审核完成判断。
3. 仅在 04 中按 B 人工补漏框，选择种类、漏检原因及备注；不要求 03 完成。没有漏检时也需要显式确认。
4. Ctrl+Enter 或完成按钮只确认 04，先保存，再自动跳到下一张未完成图片；没有其他待处理图片且本图 03 未完成时返回 03，保存失败时不跳图。图片列表与 Excel 分别体现 03 / 04 状态，只有两步都完成才算整图完成。零检出图片也要检查，M 同样可以找到未完成图片。
5. R 返回算法审核并恢复原算法显示选项。修改实际判定或漏检框会重新待复核，撤销同时恢复之前的完成状态。

新增快捷操作：左上角按住看全部 H，与右上角显示 GT G 对称；Ctrl+1 把本图全部算法目标设为正检，并支持一次撤销。非当前算法标签的开关始终可用，影响持续显示和按住临时显示。

GT 与人工决策分离：IoU 自动匹配仅作参考提示，不自动补漏、不从 GT 转换最终结果，也不因导入 GT 改变完成状态。漏检条目来自测试人员的人工补框，原始 GT 文件保持不变。右侧 GT / 人工补框单击只查看；双击人工补框行可显式进入漏检编辑。

存储格式 version 2 支持图级复核状态、批量撤销以及旧版数据迁移；未完成算法目标的原因草稿和待确认标记也会保存。历史 GT 标记保存在 reference_annotations，旧算法漏检标记保留供重新审核。
